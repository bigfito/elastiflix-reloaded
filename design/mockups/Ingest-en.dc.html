Rules: every field must exist in the index mapping and have its type (release_date as yyyy-MM-dd, adult as a boolean, keywords and belongs_to_collection as nested objects); id, title and plot are required, and id can't repeat. A placeholder plot, or one shorter than 40 characters, rejects the file. A 0 in budget, revenue, runtime, vote_average or vote_count is stored with no value; a repeated list value is skipped; a plot with language-model leftovers, a themes essay, or repeated in the file, is only a warning. The whole file is validated before anything is written: if a single record doesn't match, the upload stops and no records are imported. In append mode, if an id already exists in the index, the record replaces the existing movie; in bulk mode, the catalog keeps only the movies in the file.
