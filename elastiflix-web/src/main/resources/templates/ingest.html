Importar .json

Si se desmarca, el archivo se rechaza. Un CSV sin encabezado no se importa.

Las listas y los objetos anidados van como JSON dentro de la celda.

  1. Comprobación en el navegador Extensión, tipo y tamaño (máximo 150 MB) antes de subir nada.
  2. Subida al servidor El servidor de aplicaciones recibe el archivo y repite las comprobaciones de tipo y tamaño.
  3. Validación contra el mapping Tipo de cada campo de cada registro; si algo no coincide, se detiene todo. id, title y plot son obligatorios.
  4. Importación en un índice temporal El índice se llama <alias>-<AAAAMMDD-HHMMSS>. Copia del catálogo actual más los registros del archivo, en lotes de 100.
  5. Publicación El alias elastiflix-reloaded pasa al índice nuevo y el índice anterior se borra, en una sola operación.

Los vectores de la sinopsis se generan para cada película con el servicio de inferencia de Elasticsearch.

Reglas: cada campo debe existir en el mapping y tener su tipo (release_date en yyyy-MM-dd, adult booleano, keywords y belongs_to_collection como objetos anidados); id, title y plot son obligatorios y id no se puede repetir. Se valida el archivo completo antes de escribir nada: si un solo registro no coincide, no se importa ninguno.

Correspondencia de columnas de vector: plot_256, plot_512 y plot_1024 se ignoran · se generarán desde plot.
