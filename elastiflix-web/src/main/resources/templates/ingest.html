No se puede cargar este archivo

Antes de subir se comprueba la extensión y el tipo (.json o .csv, sin dobles extensiones), el tamaño (máximo 150 MB) y que el contenido sea texto UTF-8. El servidor repite estas comprobaciones al recibirlo.

Si se desmarca, el archivo se rechaza. Un CSV sin encabezado no se importa. Las listas y los objetos anidados van como JSON dentro de la celda.

Proceso de carga

  1. 1Comprobación en el navegador · pendienteExtensión, tipo y tamaño (máximo 150 MB) antes de subir nada.
  2. 2Subida al servidor · pendienteEl servidor de aplicaciones recibe el archivo y repite las comprobaciones de tipo y tamaño.
  3. 3Validación contra el mapping · pendienteTipo de cada campo de cada registro; si algo no coincide, se detiene todo.
  4. 4Importación en un índice temporal · pendienteCopia del catálogo actual más los registros del archivo, en lotes de 100.
  5. 5Publicación · pendienteEl alias elastiflix-reloaded pasa al índice nuevo y el índice anterior se borra, en una sola operación.
